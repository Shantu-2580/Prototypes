# About

This repository contains my collection of hardware and embedded engineering prototypes.

Instead of polished end products, this repository documents experiments, PCB designs, robotics projects, firmware, and proof-of-concepts developed while exploring electronics and embedded systems.

Some projects are complete.

Some are works in progress.

Every project contributes to learning.
